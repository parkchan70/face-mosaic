# 얼굴 모자이크

사진 속 얼굴을 자동으로 찾아 모자이크, 블러, 스티커로 가리는 웹 앱입니다.
사진은 서버로 보내지 않고 브라우저 안에서만 처리합니다. (처음 열 때 얼굴 인식 모델 약 5MB만 내려받습니다.)

## 사용 방법

1. `index.html`을 브라우저로 엽니다.
2. 사진을 끌어다 놓거나 **사진 고르기**를 누릅니다. 여러 장을 한꺼번에 올릴 수 있고, Ctrl+V로 붙여넣어도 됩니다.
3. 오른쪽에서 가리는 방법을 고르면 올린 사진 전체에 한꺼번에 적용됩니다.
4. **이 사진 저장** 또는 **전체 저장**을 누릅니다. 여러 장은 ZIP 파일 하나로 받습니다.

## 가리는 방법

| 방법 | 알맞은 경우 | 조절할 수 있는 것 |
|---|---|---|
| 모자이크 | 가장 흔하게 쓰는 깔끔한 가리기 | 모자이크 칸 크기 (큼직하게 ~ 잘게) |
| 블러 | 사진 분위기를 덜 해치고 부드럽게 가릴 때 | 흐림 정도 (살짝 ~ 강하게) |
| 스티커 | 아이들 사진처럼 귀엽게 가리고 싶을 때 | 이모지 12가지 또는 내 이미지 |

- **가릴 범위**: 얼굴만 가릴지, 머리카락까지 넉넉히 가릴지 정합니다.
- **모양**: 모자이크와 블러는 타원 또는 사각형으로 가릴 수 있습니다.
- **내 이미지 올리기**: 학교 마스코트 같은 그림을 스티커로 씁니다. 배경이 투명한 PNG가 가장 자연스럽습니다.

## 얼굴 하나하나 다듬기

- **가리지 않을 얼굴**: 노란 테두리를 누르면 점선으로 바뀌고 그 얼굴은 가리지 않습니다. 다시 누르면 다시 가립니다.
- **못 찾은 얼굴**: 사진 위를 드래그해서 네모를 그리면 그 부분이 추가로 가려집니다. 직접 그린 주황 테두리는 다시 누르면 지워집니다.
- **감지 민감도**: 오른쪽으로 올릴수록 애매한 얼굴까지 가립니다. 얼굴이 아닌 곳이 가려지면 조금 내립니다.
- **작은 얼굴까지 찾기**: 사진을 여러 조각으로 나눠 다시 살펴서 단체 사진 뒷줄의 작은 얼굴까지 찾습니다.
- **누르는 동안 원본**: 누르고 있으면 가리기 전 사진이 보입니다.
- **얼굴 테두리**: 끄면 테두리 없이 결과만 봅니다. 테두리는 저장하는 사진에 들어가지 않습니다.

## 저장

- 원본과 같은 해상도로 저장되고, 파일 이름 뒤에 `_가림`이 붙습니다.
- 저장 형식은 원본과 같게, JPG, PNG 중에서 고릅니다.

## 참고

- 자동 인식이 모든 얼굴을 찾지는 못합니다. 저장하기 전에 꼭 눈으로 확인하고, 못 찾은 얼굴은 드래그로 추가해 주세요.
- 아이폰 HEIC 사진은 브라우저에서 열리지 않을 수 있으니 JPG로 바꿔서 올려 주세요.

- [JSZip](https://stuk.github.io/jszip/) – 여러 장 ZIP 저장
